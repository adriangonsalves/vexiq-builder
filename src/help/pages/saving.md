Your builds save themselves, so there is no Save button. Use **File** to start, switch and back up.

1. {{Click the build's name (1) at the top left, type a new name, then press `Enter`.|The toolbar has no name box here. Choose **File → Load…**, then [[Rename]] on the build.}}
   ![The build's name marked in the toolbar](shot:saving-name)
2. Open **File** [[File]] (1) and choose **New** (2) for an empty build. The old one stays saved.
   ![The File menu with New marked](shot:saving-new)
3. Open **File** (1) and choose **Load…** [[File → Load…]] (2) to see your builds.
   ![The File menu with Load… marked](shot:saving-load)
4. {{Click|Tap}} [[Open]] (1) on the build you want.
   ![The builds window with Open marked](shot:saving-open)
5. Open **File** (1) and choose **Export** (2) to download a copy.
   ![The File menu with Export marked](shot:saving-export)

> **Watch out** Builds live only in this browser, so Export a copy to keep it safe.

## Why to Export
Clearing the browser's data, or using a different browser or computer, loses your builds. Export downloads the build as a file. To bring it back, choose **File → Load…**, then [[Open from computer…]], and pick the file. It opens as a new build.

## What Load… can do
Each build shows a picture, its name, when it changed and how many parts it has. The one you are in says "Open now".
- [[Open]] switches to that build. Double-clicking it works too.
- [[Rename]] (the pencil) lets you type a new name.
- [[Duplicate]] (two squares) makes a copy, named with "copy" at the end.
- [[Delete]] (the bin) asks first, then removes it.
- [[Open from computer…]] adds a build file as a new build.

You can also rename from the build's name at the top.

## Delete this build…
Choose [[File → Delete this build…]] to remove the build you are in. It asks first, and it can't be undone. Then the app opens your most recent other build, or a new empty one.
![The File menu with Delete this build… marked](shot:saving-delete)

## When the browser can't save
Some private windows turn off storage. The builds window then says so. **New**, **Starter** and **Export** still work, so Export before you close.
