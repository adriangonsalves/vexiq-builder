Gears pass turning from one shaft to the next.

1. Add a gear from the **Library** [[Library]].
2. {{Drag it with the arrows, or press `W` for Move | Tap **Move** [[Move]] on the context bar, then drag an arrow}}.
3. Put it next to another gear so the teeth meet. The toolbar's **Tools** button (1) has more.
   ![The toolbar with the Tools button marked](shot:fixture-toolbar)
4. Select a part, then use **Join** [[Join]] to push it onto a shaft.

> **Watch out** A gear on a round shaft spins freely.

## If a gear won't turn
Check that both gears are on shafts that can spin. See [Build your first thing](help:quick-start).
